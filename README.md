# CV Website

This is a GitHub repository for a personal CV / resume static website. The site showcases a resume, skills, education, and work experience.

## About the project
- The website is created as a digital business card and online resume.
- It includes information about professional experience, skills, and contact details.
- It is designed for easy sharing and presentation on the internet.

## Running the website

`npm run serve`

## Status
The site is still under development. New sections are being added, content is being optimized, and the design is continuously updated.
